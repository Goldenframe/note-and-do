# DList

Приложение для задач и заметок. Задачи можно отмечать выполненными и важными, а удалённые записи можно восстановить из корзины в течение текущего сеанса. Активные задачи и заметки сохраняются в браузере.

Стек: React, TypeScript, Jotai, Vite.

## Запуск

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```
