# DList - Приложение для управления задачами и заметками

DList - это современное веб-приложение для управления задачами и заметками, построенное с использованием React, TypeScript и Vite с архитектурой Feature-Sliced Design (FSD).

## Технологии

- **React 18** - Библиотека для построения пользовательских интерфейсов
- **TypeScript** - Статическая типизация для надежности кода
- **Vite** - Быстрый сборщик и dev-сервер
- **React Router DOM** - Клиентская маршрутизация
- **FontAwesome** - Иконки и UI элементы
- **Feature-Sliced Design** - Архитектурная методология для масштабируемых приложений

## Архитектура проекта (FSD)

Проект организован по методологии Feature-Sliced Design:

```
src/
├── app/                    # Инициализация приложения, провайдеры, стили
├── pages/                  # Страницы приложения (композиция виджетов)
├── widgets/                # Независимые виджеты (крупные UI блоки)
│   ├── layout/            # Layout приложения
│   ├── notes/             # Виджет заметок
│   └── todos/             # Виджет задач
├── features/               # Бизнес-фичи пользователя
│   ├── notes/             # Фичи работы с заметками
│   └── todos/             # Фичи работы с задачами
├── entities/               # Бизнес-сущности
│   ├── notes/             # Сущность заметки
│   └── todos/             # Сущность задачи
└── shared/                 # Переиспользуемый код
    ├── ui/                # UI компоненты (кит)
    ├── lib/               # Утилиты, хуки, типы
    └── api/               # API клиенты
```

## Основные возможности

### Управление заметками
- Создание, редактирование, удаление заметок
- Организация по категориям: "Все", "Корзина"
- Автоматические временные метки
- Адаптивный дизайн с поддержкой свайпов на мобильных устройствах
- Корзина с автоматической очисткой через 5 минут

### Управление задачами
- Создание, редактирование, выполнение задач
- Расширенная категоризация: "Все", "Избранное", "Не выполнено", "Выполнено", "Корзина"
- Отметка задач как важные (избранные)
- Полная поддержка мобильных устройств
- Корзина с временным хранением удаленных задач

### Пользовательский интерфейс
- Современный Material-Design инспирированный дизайн
- Полностью адаптивный интерфейс
- Полная поддержка доступности (WCAG)
- Управление с клавиатуры
- Поддержка touch-жестов

## 🛠 Установка и запуск

### Предварительные требования
- Node.js 18+ 
- npm или yarn

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```

### Сборка для production
```bash
npm run build
```

### Превью сборки
```bash
npm run preview
```

### Линтинг кода
```bash
npm run lint
```

## Скрипты

- `npm run dev` - Запуск dev-сервера
- `npm run build` - Сборка production версии
- `npm run preview` - Превью собранного приложения
- `npm run lint` - Проверка кода с ESLint
